# Profiles of OGC standards using CC profiles

Working space for exploring Creative Commons 


TASL is described [here](https://wiki.creativecommons.org/wiki/Recommended_practices_for_attribution)


## Building Blocks

### `ogc.profiles.cc.tasl` — TASL profile of DCAT

**Type:** model

Provides a CI/CT/CD environment for the TASL profile definition.

### `ogc.profiles.cc.taslar` — TASLAR profile of DCAT/TASL

**Type:** model

TASLAR extended profile definition.

### `ogc.profiles.cc.tasl-json` — Simple JSON properties for CC TASLAR profile

**Type:** schema

A set of properties that can be added to any object enforcing TASLAR 

### `ogc.profiles.cc.stac.extensions.stac-taslar` — STAC TASLAR Extension

**Type:** schema

Placeholder for a STAC TASLAR extension - defines

### `ogc.profiles.cc.stac.extensions.geodcat-stac-tasl` — GeoDCAT profile of STAC TASL extension

**Type:** schema

Defines a STAC extension for implementing the TASL profile
